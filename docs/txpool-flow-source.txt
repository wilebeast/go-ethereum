Geth TxPool Flow With Source References
======================================

Legend
======

- [file] means the primary source file
- func(...) means the key function / method
- DROP means the transaction is rejected or removed from the pool
- DEMOTE means a pending tx is moved back to the future queue

ONE-LINE SUMMARY
================

TxPool.Add
 -> LegacyPool.Add
 -> ValidateTxBasics
 -> add / validateTx
 -> if full: priced.Underpriced / priced.Discard
 -> pending replacement OR enqueueTx -> queue.add
 -> requestPromoteExecutables
 -> runReorg -> queue.promoteExecutables -> promoteTx -> pending
 -> reset / demoteUnexecutables / truncatePending / truncateQueue may DROP or DEMOTE
 -> miner reads txpool.Pending
 -> miner orders account heads by price/time
 -> Shift reveals next nonce per account
